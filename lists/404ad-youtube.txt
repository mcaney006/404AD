! Title: 404AD YouTube Adapter
! Description: Network and cosmetic rules paired with the YouTube runtime
! adapter in the extension. The adapter handles the player state machine; these
! rules handle everything that is a plain request or a plain selector.

! ---------------------------------------------------------------------------
! Ad-serving endpoints used by the web player.
! Note: /youtubei/v1/player is NOT blocked. It carries the playback config the
! player needs; the runtime adapter strips the ad payload out of the response
! object instead, which is why blocking it here would break playback entirely.
! ---------------------------------------------------------------------------
||youtube.com/api/stats/ads$xmlhttprequest
||youtube.com/pagead/$xmlhttprequest
||youtube.com/ptracking$xmlhttprequest
||youtube.com/api/stats/qoe$xmlhttprequest
||youtube.com/youtubei/v1/log_event$xmlhttprequest
||googlevideo.com/videoplayback*&oad$media
||googlevideo.com/initplayback*&adformat$media
||youtube.com/get_midroll_info$xmlhttprequest
