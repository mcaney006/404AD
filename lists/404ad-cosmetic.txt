! Description: EasyList-style element hiding.
!
! Discipline for generic rules, enforced by the risk model and by review:
!   * every generic selector is anchored on a class or id token, so the runtime
!     index can skip it unless that token is in the document;
!   * no bare element selectors, no universal selectors, no token shorter than
!     six characters. `.ad` matches `.address`-adjacent utility classes on real
!     sites; `.ad-slot-container` does not.
! Site-specific rules carry no such restriction, because their blast radius is
! already bounded by the host.
